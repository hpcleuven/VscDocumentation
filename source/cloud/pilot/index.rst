#########################
:fas:`vial` Tier-1 Cloud Pilot
#########################
.. warning::

   This section of the documentation is WIP and intended for users that signed up for the pilot.
   If you are using OpenStack and did not sign up for the pilot, this documentation does not apply. You can find the regular documentation here: :doc:`../index`

The VSC cloud platform uses the open-source software
`OpenNebula <https://opennebula.io>`_. This
guide explains the specifics of the VSC environment, and provides a
hands-on introduction to OpenNebula. For reference, you should consult
OpenNebula's own documentation at
`docs.opennebula.io <https://docs.opennebula.io>`_.

For all questions concerning the VSC cloud computing platform,
please contact `cloud@vscentrum.be <mailto:cloud@vscentrum.be>`_.

We welcome your feedback, comments and suggestions for improving
the documentation.
