Components of AI tools
======================

Broadly speaking, AI tools consist of three key components, the large language
model (LLM), the AI agent, and the harnessing framework.
Nowadays, the integration of these components with various end-user tools
is ever-growing. This empowers users to leverage AI capabilities seamlessly
within their HPC environments. AI tools can be deployed either locally on the
user's machine or remotely on the VSC cloud and/or compute environments.

In the context of HPC, using AI tools can be coarsely categorized into two main types:

* coding assistants, and 
* agentic AI

    cloud services), you need to fully adhere to the generative AI policy and guidelines
    mentioned in the `VSC AI policy <ai_charters>`_ page.


.. _ai_coding_assistants:

AI coding assistants
--------------------

The AI coding assistants help users write, debug, and optimize code efficiently.
These tools are mostly integrated in Interactive Development Environments
(IDEs, such as Eclipse, Visual Studio Code, JetBrains IDEs, and others) to assist
the software developers at different stages of code development. In real-time,
AI assistants provide code generation, code suggestions, code completion, error
detection and code review based on natural language descriptions.


.. _gen_ai:

Agentic AI
----------

AI agents are autonomous systems that can perform tasks on behalf of humans, often by
interacting with multiple tools and services. 
Agentic AI is a paradigm where AI agents operate autonomously to perform tasks,
make decisions, and interact with the underlying (HPC) system on behalf of humans.
